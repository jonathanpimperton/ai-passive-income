Use the [US Salary Calculator](/tools/income-and-planning/salary-us/) to enter your situation: set the state tax rate (the calculator takes one flat effective rate; for California at this salary, income tax plus SDI is {{ (((0.01 * max(0, min((100000 - 5900), 11456) - 0) + 0.02 * max(0, min((100000 - 5900), 27157) - 11456) + 0.04 * max(0, min((100000 - 5900), 42861) - 27157) + 0.06 * max(0, min((100000 - 5900), 59498) - 42861) + 0.08 * max(0, min((100000 - 5900), 75197) - 59498) + 0.093 * max(0, min((100000 - 5900), 384109) - 75197) - 158) + (100000 * 0.013)) / 100000 * 100) | pct1 }}), the filing status and the 401(k) contribution.
