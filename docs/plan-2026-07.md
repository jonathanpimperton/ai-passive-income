## PHASE 2 — Design Overhaul: "Precision Instrument" (NOT STARTED)

Sequence (each step ships independently; screenshots before/after for owner sign-off):
1. **Tokens:** ink #0E1116 / paper #FCFCFA palette in global.css @theme; teal sole accent;
   semantic tokens (bg-surface / text-ink / border-line) replacing the fragile 260-line
   `[data-theme=dark]` override list. Semantic number colors: gains = ink/green,
   costs = red; NEVER coral on positive money (currently take-home pay renders coral-red).
2. **Typography:** single grotesk (Inter Tight or Space Grotesk, self-host woff2) for
   everything; JetBrains Mono (subset to ~28KB) for every financial figure, table column,
   axis tick, result number; real type scale (14/16/20/28/40/56); drop Libre Baskerville.
3. **Core components:** SliderInput visual redo (16-18px thumb, 4-6px track, no overhang,
   value bubble on drag, 1px ring); one Badge component (2 variants max — currently 5+
   pill styles per page); buttons; cards 1px border no shadow; affiliate cards as quiet
   recommendation rows; logo wordmark re-set in brand face (current SVG is hand-traced,
   wobbly), currentColor for dark mode.
4. **Chart system:** shared chartTheme module for all 23 calculators — solid faint grid
   (no dashes), series1 teal 2px / series2 neutral-400, direct end-labels (no legend on
   2-series), neutral tooltip card with mono values, donut center KPIs ("78% kept"),
   annotated crossover markers ("interest overtakes your deposits in year 14"), 300ms
   count-up on headline numbers, dark-mode aware (current legend is illegible in dark).
5. **Page chrome:** compact light interior headers replace the 260-330px empty navy
   "aurora" bands (brand incoherence: homepage is light, interiors dark); solid 1px
   hairlines replace ALL gradient dividers; delete gradient-text utilities (.result-number,
   .stat-number); prose sections get sticky "On this page" TOC (kills dead right column).
6. **Calculator page recomposition:** marketing module diet — ONE email capture per page
   (kill either inline box or scroll bar); ResultAffiliate moves below the schedule table
   (currently interrupts results between buttons and chart); trim affiliate box; sticky
   summary-only results header (fixes nested-scrollbar trap + broken sticky thead);
   mobile sticky mini-result bar (real-time USP currently invisible on phones — results
   are 2 screens below inputs); fix ragged mobile button row (EmailResultsButton
   items-end); bottom-edge collision (cookie banner + scroll bar + FAB).
7. **Homepage:** restyle hero to new system; REPLACE Solar tab with "What's my take-home
   pay?" (UK + US — also restores the regressed UK prompt from Sprint 33A); "Open full
   calculator" becomes solid primary CTA (currently pale ghost pill outshone by cookie
   Accept); tabs get clickable affordance; below-fold sitemap-dump becomes designed rows
   with precomputed result previews in mono numerals ("£50K salary → £3,101/mo take-home"
   — values from docs/tax-values-2026.json); trust strip under hero (ACA credential →
   /about, "every calculator shows its formula" → methodology links, tax-year
   verification); differentiator proof strip ("44 calculators · results as you type ·

   its card. Keyworded H2 for discovery section + keyworded subhead line.
