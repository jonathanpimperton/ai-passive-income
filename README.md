# AI Passive Income

An experiment in building a zero-investment online business entirely with AI (Claude Code).

## The Idea

A focused **financial calculator site** that generates passive income through affiliate partnerships and display ads. All tools are interactive, client-side, and free to use.

## Tech Stack

- **Astro** + TypeScript (static site generation, React islands for interactive tools)
- **Tailwind CSS v4**
- **Cloudflare Pages** (free tier — unlimited bandwidth, commercial use allowed)

## Status

**Stages 1-3 complete. Stage 4 (Build) — Sprints 1-5 complete.**

- Stage 1: Explored 6 business models → selected free tools site
- Stage 2: Market research, financial model, competitor analysis
- Stage 3: Revised plan after 2026 market reality check (AI Overviews, ad RPM crash, framework choice)
- **Stage 4: Build** — 32 tools live (14 financial calculators + 4 utility tools + 14 file converters)

See `docs/strategy.md` for the full plan.
