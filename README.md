# AI Passive Income

An experiment in building a zero-investment online business entirely with AI.

## The Idea

Use Claude Code to research, plan, build, and launch an online product that generates passive income — with absolutely no upfront monetary investment.

## Stages

1. **Exploration** — Research viable passive income ideas (directories, tools, content sites, etc.)
2. **Detailed Plan** — Pick the best idea and plan the MVP
3. **Optimize** — Refine the plan for fastest time-to-revenue
4. **Build** — Develop the MVP with Next.js + TypeScript
5. **Test & Review** — QA, SEO audit, performance
6. **Go Live** — Deploy and start generating traffic

## Tech Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Supabase (free tier)
- Vercel (free tier)
